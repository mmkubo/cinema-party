# CINEMA PARTY（仮）
## サイト概要
### サイトテーマ
映画を中心に人が集まり、その時に感じたことや「好き」を共有しながら、同じ作品を誰かと一緒に楽しめる映画SNSです。
​
### テーマを選んだ理由
私は映画が好きで、普段から映画情報サイトや映画記録サービスを利用しています。しかし、映画を観るたびに過去に観た作品と比較しながら星の数を決めることを、煩わしく感じることがありました。それよりも、「このシーンが好き」「最後が衝撃だった」といった、その時に感じたことを気軽に共有したいと思うことが多くあります。

また、テレビで映画が放送されている時に、SNSで同じ作品を観ている人たちの反応を見ながら盛り上がることにも楽しさを感じています。一方、一般的なSNSではさまざまな話題が流れるため、その映画を観た人の感想をまとめて見ることは難しいと感じています。映画ごとに感想が集まることで、同じ作品を観た人たちと一緒に盛り上がれる場所があればよいと考えました。

現在は動画配信サービスによって、好きな作品を好きな時間に観ることができます。その良さはそのままに、感想や観る予定を緩く共有することで、映画体験を誰かと重ねることもできるのではないかと考えています。また、同じ映画でも感じ方は人それぞれであるため、一つの平均点ではなく、一人ひとりの感想を見ることで自分に合いそうな映画を探したい人もいると考えました。

そこで、映画を一つの点数で評価することを中心とせず、映画を観た時の感想や観る時間を緩く共有できる場所を作ることで、映画を介した交流や新しい作品との出会いにつなげたいと考え、このテーマを選びました。
​
### ターゲットユーザ
- 映画を観た時の感想や反応を、気軽に誰かと共有したい人
- 同じ作品を観た人の率直な感想や反応を知りたい人
- 好きな時間に映画を楽しみながら、他の映画好きと映画体験を共有したい人
- 平均評価だけではなく、さまざまな人の感想から自分に合いそうな映画を探したい人
- 観たことのある映画の内容や場面は覚えているものの、タイトルが分からず探している人
​
### 主な利用シーン
- 映画を観た直後に、その時に感じたことを誰かと共有したい時
- 映画を観ながら、同じ作品を観ている人の反応を楽しみたい時
- これから観る映画や観る予定を、他の映画好きと共有したい時
- 星の数にとらわれず、さまざまな人の感想から次に観る映画を探したい時
- 昔観た映画の内容や場面は覚えているものの、タイトルを思い出せず探したい時
